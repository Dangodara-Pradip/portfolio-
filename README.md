# React.js Personal Portfolio Website

A modern and responsive personal portfolio website developed using **React.js, JavaScript, HTML, and CSS**. This project is designed to showcase my frontend development skills, technical knowledge, live projects, and professional profile.

## 🚀 Features

* Responsive and modern UI design
* React.js component-based architecture
* Interactive navigation
* About Me section
* Technical Skills section
* Featured Projects section
* Live project links
* Contact information
* Animated background elements
* Responsive design for different screen sizes
* Modern gradient and glassmorphism-style UI

## 🛠️ Technologies Used

* React.js
* JavaScript
* HTML5
* CSS3
* Git & GitHub
* REST APIs

## 📂 Project Sections

* **About Me** – Introduction and frontend development profile
* **Skills** – JavaScript, React.js, HTML, CSS, Git & GitHub, REST APIs, Database Management, and Communication
* **Projects** – Showcase of completed and live projects
* **Contact** – Email, phone, LinkedIn, and GitHub information

## 🎯 Purpose

The main purpose of this project is to create a professional online portfolio where I can showcase my frontend development skills, projects, and learning journey while connecting with recruiters, companies, and other developers.
